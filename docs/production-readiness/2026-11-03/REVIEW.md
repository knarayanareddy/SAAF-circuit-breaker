## Architecture and product boundary

The root Next.js app has an intercept API: `POST` parses input then calls `processIntercept`; `GET` retrieves a session by ID ([route:9-27](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/app/api/sentinel/intercept/route.ts#L9-L27)). `processIntercept` locks and reads PostgreSQL session state, computes local assessment, calls external Jev, then builds and persists a workpaper and state within a transaction ([live-sentinel:33-101](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/lib/live-sentinel.ts#L33-L101)). It returns `paymentExecuted: false`; the README says neither external refunds nor real reviewer notifications occur. PostgreSQL is required by [src/db/index.ts:5-19](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/db/index.ts#L5-L19).

The nested Python project is separate: [pyproject.toml:16-21](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/pyproject.toml#L16-L21) exposes CLI entry points; [main.py:65-90](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/cli/main.py#L65-L90) loads a ticket and policy, and [main.py:152-166](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/cli/main.py#L152-L166) renders reports. Do not assume the two implementations share a runtime or provider path.

## Findings ledger

**F1 — High, confirmed static; exposure-dependent: session API has no authentication or ownership check in the sampled handlers.** [route.ts:9-27](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/app/api/sentinel/intercept/route.ts#L9-L27) takes `sessionId` and returns `NextResponse.json(session)` without a visible principal check; POST also invokes the transition without one. The identifier is validated, not an authorization credential. Anyone who can access this route and knows an ID can request its session and submit transitions; session data includes prompt, memory and trace. This is consistent with the explicitly local prototype, not evidence of a publicly exposed service. Keep loopback isolation; before broader access implement identity, per-session authorization and endpoint-wide access controls, and test denial across users.

**F2 — Medium, confirmed static: Python report interpolates untrusted fields into HTML.** [html_exporter.py:6-22](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/ledger/html_exporter.py#L6-L22) writes `wp.get('workpaper_id')`, event fields and `audit_standard` directly into HTML; [cli/main.py:152-166](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/cli/main.py#L152-L166) generates the report before exiting on failed verification. A crafted imported workpaper can therefore put markup or script into a report opened by a reviewer, including when verification fails. Escape every dynamic HTML text value and test malicious input on the actual CLI-to-report path. Impact depends on opening an attacker-supplied report; no exploitation was run.

**F3 — Medium, confirmed static / unverified operational risk: network call holds a database transaction and session lock.** [live-sentinel.ts:36-49](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/lib/live-sentinel.ts#L36-L49) takes an advisory transaction lock before `await judgeWithJev`, whose [jev.ts:21-25](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/lib/jev.ts#L21-L25) specifies an eight-second timeout. Slow or concurrent requests can occupy pool connections and delay other requests; the magnitude and actual pool behavior were not measured. Evaluate a version-checked two-phase design or strictly bounded admission while preserving atomic state transitions and fail-closed behavior.

**F4 — Medium, confirmed boundary: workpaper hashes are not authenticated provenance.** The [README:9](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/README.md#L9) says “hashes check consistency, not signatures or certified compliance.” The [integrity test:85-101](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/tests/workpaper-integrity.test.ts#L85-L101) tests rehashed rule violations, not trusted signers. Consistency does not establish authorship or prevent a different internally consistent history. The owner must decide whether authenticated provenance and key management are required.

**F5 — Low, historical CI, not a current test result.** The snapshot records a successful [Pages build and deployment](https://github.com/knarayanareddy/SAAF-circuit-breaker/actions/runs/37489472901) at the pinned SHA. It does not establish that either application test suite, database migration, or provider integration ran. The complete snapshot tree has no `.github/workflows` path; Pages may be configured outside repository workflow files. Define separate application gates rather than treating that Pages result as a test pass.

## Five-discipline assessment

1. **Correctness / code review:** [sentinel-api.test.ts:75-127](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/tests/sentinel-api.test.ts#L75-L127) describes outage, deterministic cap, persisted rollback and same-session concurrency assertions. These are test source, not observed passes. Provider compatibility, transaction rollback on partial failure, and cross-runtime equivalence remain unverified.
2. **Automation / testing:** [package.json:4-12](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/package.json#L4-L12) defines `test`, `typecheck`, `lint`, `build` and database scripts; [Python ingress tests:11-35](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/tests/test_runtime_ingress.py#L11-L35) assert malformed inputs halt and failed verification exits nonzero. Neither suite was run. Pages success is not a substitute.
3. **DevOps / operations:** DB configuration fails if `DATABASE_URL` is missing; backup, restore, migration compatibility, pool exhaustion, concurrency under load and deploy topology were not checked. The README separates fresh `db:push` and additive migration, but no restore has been observed.
4. **OWASP / security:** F1 covers authentication and authorization, F2 HTML injection, F4 data authenticity. [jev.ts:18-52](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/lib/jev.ts#L18-L52) reads server environment keys, sends bearer authentication to a fixed endpoint and avoids returning raw transport errors; secret exposure in artifacts and logs remains untested. [live-sentinel.ts:47-80](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/src/lib/live-sentinel.ts#L47-L80) sends prompt/memory to the provider and persists them locally: consent, retention, access and deletion are unverified. Node uses a lockfile per tree, while [Python requirements:6-14](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/pyproject.toml#L6-L14) specify minimum versions; dependency integrity and advisories were not audited.
5. **UI / UX / accessibility:** the web app and Python CLI are applicable interfaces, but no browser rendering, keyboard, screen reader, contrast or usability inspection was performed. [CLI:157-166](https://github.com/knarayanareddy/SAAF-circuit-breaker/blob/f3c59dac16200c3f4c29da4f0448dbba4f1c0ef1/saaf-circuit-breaker/cli/main.py#L157-L166) prints verification and returns failure status, a useful automation contract; report safety remains F2. Demo wording must not imply an actual payment or human notification.
